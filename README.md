# Labs

Three self-contained design/schedule playgrounds. No build, no install — open any `.html` file in a browser.

- **text-lab.html** — title & tile text animations
- **graph-lab.html** — chart styles, colors, 3D, backdrops
- **schedule-lab.html** — tasks over a readiness curve (natural-language input, gaps, locks, live styling); remembers your tasks in the browser

`index.html` is a landing page linking to all three.

Everything is inline (CSS + JS) — the only external thing is Google Fonts. The labs link to each other by filename, so keep all four files in the same folder.
